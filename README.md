## featured projects

### ⚙️ Data Processing & Analytics Engine
**Python · FastAPI · PostgreSQL · Redis · Celery · Docker**

- Built a containerized backend system for asynchronous CSV processing with persistent job tracking.
- Implemented chunked processing and cross-chunk deduplication, reducing peak memory usage by **65%** on ~5 million records.
- Developed benchmarking tools to compare execution time, throughput, and memory efficiency.

### 🏥 Clinical Compass
**Python · Flask · PostgreSQL · Apache Airflow · Docker · Supabase**

- Built and deployed an automated ETL pipeline aggregating **190+ hospital job postings** to help nursing students discover opportunities.
- Automated weekly data collection using Apache Airflow and Docker.
- Developed a searchable Flask web application backed by PostgreSQL.

### 🗺️ Toronto Food Intel
**Python · SQL · PostgreSQL · Pandas · Power BI · Folium**

- Built an end-to-end ETL pipeline processing **10,700+ restaurant records** and 68 TTC stations.
- Analyzed restaurant density, cuisine distribution, and transit accessibility using SQL.
- Created an interactive Power BI dashboard and Folium map to visualize Toronto's food landscape.
